# DEMO Coaching Institute - Modern 3-Page Website

A premium, modern Indian coaching institute website for **DEMO**.

## 🚀 Quick Start with Vite

Make sure you have [Node.js](https://nodejs.org/) installed, then run the following commands inside this directory:

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Your default browser will automatically open at `http://localhost:3000/`.

### 3. Production Build
```bash
npm run build
```
Creates an optimized, production-ready build in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 📁 Multi-Page Structure

- **`index.html`**: Page 1 — Home (Hero, About, Statistics, Programs, Why DEMO, Results, Faculty, Testimonials, Final CTA)
- **`courses.html`**: Page 2 — Courses & Batch Timetable (Category Filters, Seats, Pricing, Batch Schedule Table, Course Modal)
- **`contact.html`**: Page 3 — Contact & Admission (Demo Booking Form with dynamic WhatsApp confirmation, Ballygunge Kolkata Address, Google Maps, 7-Item FAQ)
- **`css/style.css`**: Design tokens, glassmorphism, animations, and custom scrollbars
- **`js/main.js`**: Course details modal, dynamic pre-filled WhatsApp links, booking form handler, and FAQ accordion
